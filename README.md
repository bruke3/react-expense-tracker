# React Expense Tracker

A simple expense tracker built with React.

## Features

- Add expenses
- Delete expenses
- Filter by category
- Calculate total spending
- Save expenses to localStorage
- Form validation

## Built With

- React
- JavaScript
- Vite
- CSS
- localStorage
